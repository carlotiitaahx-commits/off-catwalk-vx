# OFF-CATWALK
### Behind every great fashion event.

**OFF-CATWALK** es una aplicación web diseñada para facilitar la planificación, organización y gestión de eventos de moda desde una única plataforma.

El proyecto se ha desarrollado como MVP (Producto Mínimo Viable) para el trabajo final del curso de IA Generativa, utilizando herramientas de inteligencia artificial como apoyo al desarrollo.

## 1. Problema que resuelve

La organización de eventos de moda requiere coordinar numerosos elementos: listas de invitados, confirmaciones de asistencia, tareas, presupuestos y cronogramas.

En muchos casos, esta información se encuentra distribuida entre hojas de cálculo, correos electrónicos y diferentes herramientas de gestión, lo que dificulta su seguimiento.

OFF-CATWALK reúne estas funciones en una misma plataforma para simplificar el trabajo de los profesionales del sector.

## 2. Público objetivo

La aplicación está dirigida principalmente a:
- Agencias de comunicación y relaciones públicas.
- Marcas de moda y lujo.
- Organizadores de eventos.
- Profesionales de marketing e influencer marketing.
- Equipos encargados de desfiles, presentaciones de colecciones y lanzamientos.

## 3. Funcionalidades principales

### Dashboard
Panel principal con una visión general del evento: invitados, confirmaciones, presupuesto, tareas completadas y próximas actividades.

### Event Details
Permite crear eventos y editar su información, incluyendo nombre, marca, fecha, ubicación, descripción y presupuesto.

### Guest List
Gestión de invitados, prensa, influencers y perfiles VIP. Permite añadir, editar y eliminar contactos, gestionar confirmaciones y realizar búsquedas y filtros.

### Task Manager
Creación y seguimiento de tareas, con responsables, fechas límite, prioridades y estados. El progreso del evento se actualiza según las tareas completadas.

### Budget Control
Registro y clasificación de gastos. Calcula automáticamente el presupuesto utilizado y el importe restante.

### Event Timeline
Organización cronológica de las actividades del evento, con horarios, ubicaciones y descripciones.

## 4. Diseño e identidad visual

OFF-CATWALK sigue una estética Luxury Editorial inspirada en las publicaciones de moda.

Su identidad visual combina negro, blanco, marfil y tonos taupe, con tipografía serif para los titulares y sans serif para los textos.

El diseño es adaptable a ordenadores, tabletas y dispositivos móviles.

## 5. Tecnologías utilizadas

- Next.js y React: desarrollo de la aplicación web.
- TypeScript: lenguaje de programación.
- Tailwind CSS: estilos y diseño adaptable.
- Componentes de interfaz shadcn/ui.
- localStorage: almacenamiento de datos en el navegador.
- v0: agente de IA utilizado para generar y modificar el código.
- GitHub: repositorio y control de versiones.
- Vercel: publicación de la aplicación.

## 6. Cómo ejecutar el proyecto

Requisitos: Node.js y un gestor de paquetes compatible con el proyecto.

1. Clonar el repositorio:

```bash
git clone https://github.com/carlotiitaahx-commits/off-catwalk-vx.git
```

2. Entrar en la carpeta:

```bash
cd off-catwalk-vx
```

3. Instalar las dependencias:

```bash
npm install
```

4. Iniciar el servidor de desarrollo:

```bash
npm run dev
```

5. Abrir http://localhost:3000 en el navegador.

## 8. Desarrollo asistido por IA

El proyecto se ha desarrollado utilizando v0 como agente de inteligencia artificial para la programación.

El proceso ha incluido la definición del problema, la selección de funcionalidades, la creación de la identidad visual Luxury Editorial, la generación del MVP y la realización de pruebas funcionales.

Las sesiones de trabajo, las instrucciones proporcionadas a la IA y las decisiones tomadas durante el desarrollo se documentan en el archivo PROMPT-LOG.md.
